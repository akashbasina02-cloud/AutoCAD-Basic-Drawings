# AutoCAD Basics

This project contains basic AutoCAD drawings created as part of college coursework.
It helps in understanding basic drawing and modifying commands in AutoCAD.

## Software Used
- AutoCAD

## Topics Covered
- Basic drawing commands
- Modify commands
- Dimensioning

## My Screen Settings

### Units
- Type: Decimal
- Precision: 0.00
- Units Scale: Millimeters
- Units for specifying intensity: International  
- Click OK

### Limits
- Lower-left corner: 0,0
- Upper-right corner: 100,100

### Grid
- Grid spacing: 10

### Zoom
- Z → A (Zoom All)

### Object Snap (OS)
- Open Drafting Settings
- Go to Object Snap tab
- Click Select All snap modes
- Click OK

### Dimension Style Manager
- Type D
- Click Modify
- Go to Symbols & Arrows → Arrow size: 3
- Go to Text → Text height: 4
- Click OK
